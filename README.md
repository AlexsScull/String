## Структура проекта

```
s21_string/
├── src/
│   ├── string.h            # Основной интерфейс библиотеки
│   ├── string_parser.h     # Внутренний API для парсинга формата
│   ├── memory_functions.c  # Работа с памятью
│   ├── string_functions.c  # Основные строковые операции
│   ├── error_functions.c   # Функции обработки ошибок (strerror)
│   ├── extended_functions.c # Специальные утилиты (to_upper, insert и др.)
│   ├── sprintf_functions.c  # Форматированный вывод
│   ├── sscanf_functions.c   # Форматированный ввод
│   ├── format_parser.c      # Общий код парсинга формата
│   ├── tests/                  # Основные тесты
│   ├── obj/                    # Объектные файлы (создаётся автоматически)
│   ├── obj_tests/              # Исполняемые тесты (создаётся автоматически)
│   ├── coverage_report/        # Отчёты покрытия кода (создаётся автоматически)
│   ├── run_tests.sh            # Скрипт запуска тестов
│   ├── checking_make.sh        # Скрипт полной проверки
│   └── Makefile                # Система сборки проекта
└── README.md
```

## Требования

- Компилятор GCC
- Библиотека Check (для unit-тестов)
- Утилиты: `make`, `lcov`, `valgrind`, `cppcheck`, `clang-format`

### Установка на Ubuntu/Debian:

```bash
sudo apt-get update
sudo apt-get install gcc check lcov valgrind cppcheck clang-format
```

### Установка на macOS (с Homebrew):

```bash
brew install gcc check lcov cppcheck clang-format
```

## Использование

### Основные команды Makefile

| Команда | Описание |
|---------|----------|
| `make all` | Сборка библиотеки |
| `make test` | Сборка и запуск всех тестов |
| `make style_check` | Проверка стиля кода |
| `make style_fix` | Автоматическое исправление стиля кода |
| `make cppcheck` | Статический анализ кода |
| `make valgrind` | Проверка утечек памяти (Linux) |
| `make leaks` | Проверка утечек памяти (macOS) |
| `make gcov_report` | Генерация отчета о покрытии кода |
| `make clean` | Очистка сгенерированных файлов |
| `make rebuild` | Полная пересборка проекта |

### Быстрая проверка

```bash
./checking_make.sh
```

Запускает полный цикл проверок проекта.

## Проверка качества кода

Проект включает несколько уровней проверки качества:

- **Проверка стиля кода** (`make style_check`)
- **Статический анализ** (`make cppcheck`)
- **Тестирование функциональности** (`make test`)
- **Проверка утечек памяти** (`make valgrind`/`make leaks`)
- **Проверка покрытия кода** (`make gcov_report`)

## Cтиль кода

Проект использует стиль кодирования Google C++ Style Guide с адаптацией для языка C.

Для автоматического форматирования используйте:
```bash
make style_fix
```

Для проверки стиля без изменений:
```bash
make style_check
```

## Тесты

Проект включает следующие тестовые модули:

- **Memory** - тесты функций работы с памятью
- **String** - тесты основных строковых функций
- **Sprintf** - тесты форматированного вывода
- **Sscanf** - тесты форматированного ввода
- **Extended** - тесты специальных функций
- **Error** - тесты обработки ошибок

### Запуск тестов

Запуск тестов производится с помощью

`make test`

Или с помощью скрипта run_tests.sh:

```bash
# Запуск всех тестов
./run_tests.sh

# Запуск с подробным выводом
./run_tests.sh +

# Запуск конкретного теста
./run_tests.sh Memory
./run_tests.sh Memory +

# Комбинирование опций
./run_tests.sh Memory String...  # Тесты Memory и String с подробным выводом
./run_tests.sh Memory String... +  # Тесты Memory и String с подробным выводом
```

## Проверка утечек памяти

make leaks      # На macOS

## Покрытие кода

Для генерации отчета о покрытии кода выполните:

```bash
make gcov_report
```

Отчет будет сгенерирован в директории `coverage_report/`. Откройте `coverage_report/index.html` в браузере для просмотра детальной информации.

## Поддерживаемые функции

### Основные функции
- `memchr`, `memcmp`, `memcpy`, `memset`
- `strcat`, `strncat`, `strchr`, `strcmp`, `strncmp`, `strcpy`, `strncpy`
- `strcspn`, `strlen`, `strpbrk`, `strrchr`, `strspn`, `strstr`, `strtok`
- `strerror`

### Дополнительные функции
- `to_upper`, `to_lower`, `insert`, `trim`, и другие

### Функции ввода/вывода
- `sprintf`, `sscanf`
